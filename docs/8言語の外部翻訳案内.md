# 8言語のオンデマンド翻訳
日本語の記事だけをCMSで管理します。訪問者が言語を選び、「Google翻訳を開く」を押すと、その時点でGoogleのウェブサイト翻訳を利用します。事前翻訳、翻訳API・モデル・データベース、専用Actions、月額サービスは使いません。

## URLと注意書き
例：記事1515のウクライナ語では、Googleの翻訳先言語をukとし、翻訳対象URLに /archive.html?post=1515&mt=uk を渡します。新規記事にも現在のIDを利用します。
- 日本語、English、Español、Français、Русский、简体中文、العربية、Українськаに対応。
- langは案内画面の選択、mtは翻訳元ページに表示する注意書きの言語。mt付きで直接開いても、記事本文の前に固定訳の注意書きと原文リンクが表示されます。mtだけでは本文は翻訳されません。
- 通常の日本語URLでは注意書きを表示しません。原文リンクでは言語・Google翻訳関連のパラメータだけを取り除き、記事IDは保持します。公開サイトのGoogle翻訳プロキシ上では日本語サイトのホストに戻します。
- アラビア語の注意書きはRTL。案内に関する文言は自サイトで生成し、翻訳対象外に指定します。

## 検証（2026-11-02）
現行公開版の記事1515をPC幅1280px・スマートフォン幅390pxのChromeで実際にGoogle翻訳経由で表示。英語・アラビア語・ウクライナ語の6条件すべてでpostとmtが残り、記事本文の冒頭（ウクライナの講演）、中ほど（生徒の追加質問）、末尾（今後も問いを追う旨）が各言語で表示されました。全195記事の訳文を検査した結果ではありません。

未公開の修正版についてはローカルHTTPで、トップ・アーカイブ・記事詳細・お問い合わせを幅1280/390/320pxで検証。各7言語のリンクが対象言語のmtを含み、日本語では注意書きなし。記事1515について全7言語のmt付きURLを直接開き、本文前に注意書きがあり、原文リンクを実際にクリックすると同じ記事の日本語表示に戻ることを確認しました。公開ビルド、195記事、トップ各5本の順序、CMSファイル、フォーム参照、JSハッシュも確認しました。

## 制約と公開後の確認
公開サイトにはこの修正がまだないため、現行公開版のGoogle翻訳画面で新しい注意書きは表示されていません。修正版を公開した後、英・アラビア・ウクライナ語で上記の記事を開き、訳文と同じ画面に注意書きが表示され、原文リンクが同じ日本語記事へ戻るかを確認してください。GoogleによるDOM・URL・リンクの書き換え、JavaScriptの制限、地域や端末による動作の違いはサイト側で制御できません。他の4言語の実際の訳文、Googleフォーム内部・外部埋め込みの翻訳も未検証です。
