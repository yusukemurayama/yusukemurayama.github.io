# 8言語切り替え

ヘッダー直下、または記事詳細の言語選択で外国語を選ぶと、同じタブでGoogle翻訳へ移動する。「日本語」を選ぶと同じページ・記事の原文へ戻る。CMSでは日本語原文を管理する。新規記事にも共通の表示処理を使う。

記事名と写真は記事ID付きのリンク。日本語版の通常クリックは従来どおりモーダルを開き、翻訳版ではリンク先のページを読み込む。検索はページ内の絞り込みなので送信用formを使わない。お問い合わせのGoogleフォームは従来どおり。

## 検証

修正前の公開英語版で記事タイトルのボタンが検索フォームの外にあることを確認した。クリックでモーダルが開いたが、報告された警告文はこの環境では再現できず、Google側の正確な発生条件は未特定。

検証用Chromeの通信でローカルの修正ファイルを差し替え、Googleの実際の翻訳画面で動作を検証した。PC幅1280pxとモバイル幅390pxで、トップページから英語への直接切り替えを確認。両幅とも英語・アラビア語・ウクライナ語の一覧から記事2111を実際にクリックし、翻訳された記事タイトル、横はみ出しなし、日本語の同じ記事への復帰を確認した。テスト中のJavaScript警告は0件。公開後は差し替えなしで再確認する。

## 参考サイト

[堀潤公式サイト](https://horijun.com/) の公開HTMLでは、インラインJavaScriptのTR・FTに各言語の文章があり、applyLangがtextContent・innerHTMLなどを書き換える。英語ボタンで同じページの言語がenになった。確認した通信はサイト本体・YouTube・Google Tag Manager等で、翻訳API呼び出しは確認されなかった。訳文の作成方法は不明。このサイトでは記事ごとに訳文を保持せず、言語選択1回で外部翻訳を開く。

外部サービスの挙動は端末・地域・ブラウザー等に依存する。全利用者の警告解消や、埋め込みコンテンツの翻訳は保証できない。
